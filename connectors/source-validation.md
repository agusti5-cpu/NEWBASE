# NEWBASE — Validació inicial de fonts

## Regla
Una font només passa a `validated` quan l'accés és autoritzat, el cost és 0 €, no exigeix subscripció ni afiliació, i l'ús comercial és compatible amb la llicència o termes de la font.

## Fonts validades inicialment

### Espanya — datos.gob.es
- Catàleg nacional de dades obertes.
- Disposa d'API i formats llegibles per màquina.
- La reutilització concreta s'ha de revisar segons la llicència de cada conjunt de dades.

### Unió Europea — data.europa.eu
- El portal europeu indica que les dades estan disponibles gratuïtament i poden utilitzar-se per crear negocis, subjecte a les condicions legals aplicables.
- Prioritat: datasets d'alt valor i APIs oficials.

### Singapur — data.gov.sg
- Portal oficial de dades obertes de Singapur.
- Disposa d'APIs públiques per a datasets i dades en temps real.
- El portal indica ús gratuït i ús comercial sota la llicència corresponent.
- Cal respectar quotas, termes de l'API i condicions específiques de cada dataset.

## Fonts no validades

Qualsevol marketplace comercial o API de tercers queda en estat `candidate` fins comprovar explícitament:

1. accés gratuït real;
2. absència de subscripció obligatòria;
3. absència de càrrecs per volum necessari;
4. permís d'ús comercial;
5. dret a mostrar/reutilitzar les dades;
6. límits tècnics compatibles amb automatització;
7. compliment de la legislació aplicable.

**No s'activarà cap connector només perquè una API existeixi.**
